Recent Cycle / Setup

Choose your coverage

The extension handles tab switching locally. An optional companion adds physical modifier state where Chrome pages are protected.

Browser-only mode is always available

Fast taps work without an install. The companion is only needed for exact hold-to-preview behavior on Chrome UI and New Tab.

macOSAvailable locally

Install the local host

Build and register the Native Messaging host automatically with the 1-line setup script:

curl -fsSL https://raw.githubusercontent.com/wahyudichrisdianto/recent-cycle/main/install.sh | bash
  1. Run the 1-line installer command in Terminal.
  2. Approve Accessibility access when macOS prompts.
  3. Already installed the extension? Re-register just the host: ... | bash -s -- --companion-only --extension-id <id>.
  4. Or manually run ./native/install.sh <extension-id>.
  5. Set the forward shortcut scope to Global in Chrome.

Privacy boundary

Only the gesture state crosses the bridge

The companion observes Option/Alt, Shift, and Tab state needed for this feature. It does not capture arbitrary characters, tab content, network data, or a keystroke history.
